# DSA Using Java

This repository is a collection of Java programs for learning and practicing Data Structures and Algorithms (DSA).  
It is organized by topic so that each concept can be studied clearly and repeatedly.

## What this repository contains

The repository includes implementations and examples for core DSA topics such as arrays, strings, linked lists, stacks, queues, trees, graphs, recursion, sorting, searching, hashing, and dynamic programming.

## Folder Descriptions

- Arrays
  - Contains programs related to array traversal, searching, sorting, insertion, deletion, prefix sums, and basic interview problems.

- Strings
  - Includes programs for string manipulation, palindrome checks, substring operations, anagrams, and pattern matching.

- Linked List
  - Covers singly linked list, doubly linked list, circular linked list, and common operations such as insertion, deletion, traversal, and reversal.

- Stack and Queue
  - Includes implementations and problems based on LIFO and FIFO concepts such as balancing brackets and queue operations.

- Trees
  - Contains code for binary trees, binary search trees, tree traversals, and basic operations like insertion, deletion, and searching.

- Graphs
  - Includes graph representation and traversal algorithms such as DFS and BFS, along with simple graph-based problems.

- Recursion and Backtracking
  - Covers recursive solutions and backtracking concepts such as permutations, combinations, subsets, and path exploration.

- Sorting and Searching
  - Includes common sorting algorithms like bubble sort, insertion sort, merge sort, quick sort, and search techniques such as binary search.

- Hashing
  - Contains examples using hash maps and hash sets for fast lookup, frequency counting, and key-value-based problems.

- Dynamic Programming
  - Includes memoization and tabulation-based solutions to classic DP problems such as Fibonacci, knapsack, and longest common subsequence.

- Miscellaneous / Practice
  - Contains extra Java practice programs and interview-style questions to strengthen problem-solving skills.

## How to Use

1. Open the folder that matches the topic you want to study.
2. Read the Java files and understand the logic.
3. Compile and run the programs in your Java environment.
4. Try modifying the code to improve your understanding.

## Learning Order

A simple order to follow is:

1. Arrays
2. Strings
3. Linked List
4. Stack and Queue
5. Trees
6. Graphs
7. Recursion and Backtracking
8. Sorting and Searching
9. Hashing
10. Dynamic Programming

## Conclusion

This repository is a practical resource for learning DSA using Java.  
It is ideal for beginners who want to build strong fundamentals and for learners who want to revise concepts regularly.
